# SUI Dashboard

Робоча папка з фронтенд-застосунком **`sui-lp-tracker`** (Sui LP & lending dashboard).

## Запуск

```bash
npm run dev
```

Команда з цього `package.json` проксується в каталог **`sui-lp-tracker`**. Див. повну документацію:

- **[sui-lp-tracker/README.md](./sui-lp-tracker/README.md)** — старт та посилання на `docs/`
- **[sui-lp-tracker/docs/ARCHITECTURE.md](./sui-lp-tracker/docs/ARCHITECTURE.md)** — архітектура й зовнішні API
